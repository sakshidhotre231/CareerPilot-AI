CareerPilot-AI

CareerPilot-AI is a smart career guidance platform designed to help students and job seekers explore career paths, track progress, and generate personalized learning roadmaps.
The system combines career recommendations with AI-powered roadmap generation to guide users toward their goals in a structured way.

Features
User Registration & Login
Career Recommendations
AI-Powered Roadmap Generation
Progress Tracking System
Career Dashboard
User Profile Management
Modern Responsive UI

Backend-

Project Modules-
Authentication Module
Handles user registration and login functionality.

Career Guidance Module
Provides career suggestions and guidance based on user interests.

AI Roadmap Generator
Generates personalized career roadmaps with phases, skills, and duration using AI.

Tracker Module
Allows users to track their learning progress.

Profile Module
Stores and manages user information.
